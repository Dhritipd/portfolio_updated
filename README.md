# Dhriti Prasad - Portfolio

A modern, responsive personal portfolio website showcasing skills, projects, and achievements as a Computer Science student.

## Overview

This portfolio features a sleek dark-themed design with neon cyan and purple accents. It includes sections for:
- **Home/Splash** - Hero introduction
- **Intro** - Brief role description
- **About** - Personal background
- **Education** - Academic timeline
- **Skills** - Technical proficiency
- **Projects** - Showcasing 6 completed projects
- **Achievements** - Notable accomplishments
- **Contact** - Contact information and social links

## Projects

1. **AgriSmart Pro** - Smart agriculture system with ML-based crop insights
2. **Genofy** - AI-powered genome health risk prediction
3. **Fake News Detection** - NLP/ML based news verification system
4. **LogSentinel** - Cybersecurity tool for Linux log analysis
5. **Sales Analysis** - Data analysis dashboard using Python/Pandas

## Tech Stack

- HTML5
- CSS3 (custom properties, animations, responsive design)
- JavaScript (vanilla)
- Google Fonts (Inter, Outfit)

## Usage

Open `index.html` in any modern web browser. No build process or dependencies required.

## Customization

Edit `index.html` to update personal information, and modify colors/fonts in `style.css`.
